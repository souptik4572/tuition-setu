# First-user session

One sitting of about an hour with a real tutor and one real week of their notes. The answers go into the post's "My First User" section and settle SPEC §18.

## Before

- [ ] Ask how much memory their laptop has (§18 Q4). 8 GB works but is slow; 16 GB is comfortable.
- [ ] Install Node 22+ and Ollama, then run `./setup.sh` the day before. The model is a 6.6 GB download.
- [ ] Ask them to bring last week's notes exactly as they wrote them: a notebook, a phone note, WhatsApp messages to themselves.
- [ ] Agree on privacy: everything stays on their laptop. Nothing about a child appears in the post without their permission, and names are changed if they want.

## During (let them drive; don't help unless they're stuck)

1. Setup wizard: their name, sign-off and PIN. Add 3–5 real students.
2. Type the week's notes the way they always do, one note per class.
3. Answer anything in **Needs you**.
4. On the weekly review, **Write updates**, then read each one. Edit, dismiss a warning, approve.
5. Send one for real, to a parent who's expecting it or to the tutor's own number first.

## Ask

1. Do parents prefer Bengali script, or Bengali written in English letters? (§18 Q1)
2. Weekly updates, or a short note after every class? (§18 Q2)
3. Should a fee reminder ever share a message with a progress update? (§18 Q3)
4. Would you pay for this? At ₹99 a month? What would make it worth more?
5. What should it do next?
6. One sentence we can quote, in their words.
